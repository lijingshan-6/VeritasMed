# v0.8 R1：父句范围内精确定位

2026-09-27，离线回归。**167 次保存的 Atomic 审计中，82 个原先无法绑定的事实恢复了位置，
没有使原本有效的事实位置失效。82 个事实的旧运行都没有语义判断，因此仍不能称为核查通过。**

算法为 [parent-exact-v1](../src/medrag/verification/parent_binding.py)。

## 比较方法与分母

固定原始模型给出的 parent_quote、answer_quotes 和判断，不重问模型。
旧方法要求片段在整个回答中唯一；新方法先定位全文唯一的父句，再要求片段在父句内部唯一。
得到的位置转换为完整回答的 Unicode code-point 偏移，保留搜索范围和所有状态。

父句不唯一/不存在、片段在父句中重复/不存在，继续 unresolved。
不猜第一处、不模糊匹配、不改写回答、不用来源里的正确数字修正待审文本。
每个返回位置都检查落在该父句内，且回答切片逐字等于引句。
这验证的是文字与范围，不验证所选父句的语义是否正确。

数据包括 data/verification/v06 下全部 164 条 atomic_v1 JSONL 记录，以及
data/demo/reliability 中 3 次**不同的** GRADE Atomic 调用；核对 audit ID 不重复。

## 恢复与剩余问题

2,169 个引句片段中，84 个由全文重复变为父句内唯一，涉及 82 个事实。
另有 28 个片段虽然全文唯一，但父句不存在，改为明确的 unresolved_parent；
其所属事实在旧规则下原本就无效，因此没有事实级定位退步。

剩余 24 个事实的位置仍无效：

| 原因 | 事实数 | 处理 |
|---|---:|---|
| 父句引文不在回答中 | 16 | 不进行全局兜底 |
| 片段引文不在已定位父句中 | 7 | 保留原始失败，不拼接成虚构原文 |
| 片段在同一父句内重复 | 1 | 保留候选，不任选一处 |

具体例子：

- **恢复：**自然回答 2823 的 fact-1 中 “microneedle patches” 在全文多次出现，
  在所给父句内只出现一次。现在能返回确定位置，但原来的未检查关系仍为 null。
- **恢复且保留待审错误：**grade-arm-swap 的 fact-2 中 “glimepiride” 在全文重复，
  在该父句中唯一。组别交换控制里原有的 “10 (0.8%)” 保持原样；找到位置并没有把错误改对。
- **仍歧义：**medical-14-paraphrase 的 fact-2 引用了 “response proportion”，
  同一父句中有两处，仍不能绑定。
- **仍缺失：**自然回答 2643 的 fact-15 给出的片段省略了中间文字，
  并非连续原文；新方法依然拒绝把这种拼接当成精确引句。

全部恢复项和全部未解决项见 [changes.jsonl](../data/verification/v08/r1-parent-binding/changes.jsonl)，
共 106 个事实条目。每条包含原记录路径/行号、case/fact ID、父句、旧绑定、新绑定和原判断。
[完整 records.jsonl](../data/verification/v08/r1-parent-binding/records.jsonl)保留所有 1,203 个事实。

## 本次能支持的结论

父句范围能解决自然长回答与 GRADE 演示中的跨句短语重复，值得进入新候选策略。
当前样本中没有程序可检测的越界/文字不一致绑定，也没有原有效事实的位置退步。
这不证明提取完整、不证明规范化 claim 保真，更不证明核查器语义更可靠。
医学构造开发/转移没有定位收益，也说明它不能代替限定语和组别映射的改进。

本次新增模型调用 **0**；新增语义判断 **0**；82 个恢复事实仍没有核查关系。
Direct / Flash 保持默认；R2 才比较新候选实际提取和核查产生的结果。

## 复现与工件

先按[研究复现指南](research-reproduction.md)下载固定 SciFact/RAGTruth 缓存，
使用轻量 Python 环境，无需 API 密钥或 GPU：

~~~sh
python scripts/verification/v08_rebind.py --output output/v08-r1-replay
~~~

输出 [protocol](../data/verification/v08/r1-parent-binding/protocol.json)、
[summary](../data/verification/v08/r1-parent-binding/summary.json)、完整逐项记录和差异表。
会核对原回答/来源指纹并重现旧绑定；若输入不符即停止，不改写旧运行。
8 项针对实际定位边界的检查覆盖重复、缺失、父句外匹配、不连续片段及 Unicode 偏移。
