## Delivered

The new `/audit` panel accepts an answer and its supplied source texts. It extracts claims,
shows supported / contradicted / insufficient judgments and binds the answer and source
quotations to exact character positions. Missing checks, ambiguous quotations and failures
remain visible. A valid location is not a correctness score.

- Direct Flash is the default; Split, Context + meta and Exact quotes v2 remain experimental.
- Ask → Audit transfers the original answer and every returned source passage, with citation
  mapping. The audit runs only when requested; it does not automatically repair the answer.
- Saved inference, new audits, bidirectional source navigation, original-paper links and
  complete JSON export work in the same panel.
- A lightweight audit service runs without Qdrant, embeddings or a GPU.
- The default no-key replay is an actual medical Ask → Audit recording, with original CC0
  paper text bundled. RAGTruth research replay remains optional after its data download.
- `python scripts/run_demo.py --medical` runs a separate original-paper collection. The old
  authored-summary corpus, research index and all frozen v0.4 experiments remain separate.

## Real medical demonstration

The GRADE hypoglycemia paper (Seaquist et al., 2024; PMC11567630) is preserved as publisher
XML, with license, identifiers and deterministic abstract extraction. One actual browser Ask
returned all five passages in 90.19 s, followed by one Direct audit in 24.093 s (7,453 reported
audit tokens). All four extracted claims were marked Supported; all input text was transferred
unchanged. [Original events, exported record and screenshots](../medical-demo.md).

This is not a medical gold test. The answer mostly quotes source sentences; a compound
results sentence remained one claim. It demonstrates the product chain and provenance,
not clinical validity, atomic-claim completeness or calibrated reliability.

## Research findings retained in this version

| Study | Observed result | Limit |
|---|---|---|
| [SciFact pilot](../verification-v0.5-pilot.md) | 25/30 label agreement | Public-label adaptation pilot, not a reliability estimate |
| [Controlled diagnostics](../verification-v0.5-diagnostics.md) | Three variants each 48/48; structured scheme 1.71× tokens | Constructed AI/developer samples; no demonstrated gain |
| [RAGTruth whole answers](../verification-v0.5-answer-audit.md) | Direct / Split each overlap 14/15 errors; warnings on 9/12 vs 7/12 unmarked answers; Split 2.55× tokens | Overlap and annotation disagreements are not semantic accuracy |
| [Context + meta](../verification-v0.5-context-audit.md) | 126 calls; 123 complete, 3 partial failures | Broader spans explain added hits; preserve all failures |
| [Specific-error and quote-v2](../verification-v0.5-specific-errors.md) | Both identify 26/33 errors in AI development review; binding-only replay completes 125/126; 36 new calls complete | AI review is not independent gold; whole-answer hits stay 3/5 for both, fixed binary 8/8 includes four easy copy controls |

The tasks have different denominators. No pooled score is reported. Repeated whole-answer
judgments still vary. Exact location handling improved, but semantic superiority has not
been established. The 60 reserved RAGTruth test source groups remain unused.

The v0.4 medical answer results remain historical: development 15/15, declared repeat 10/10,
first held-out test 31/35. Those 35 questions are exposed, and all four failures remain.
They do not measure the independent v0.5 audit panel. [Original report](../agent-v0.4-flash-report.md).

## Release scope and next work

v0.5 is a runnable, inspectable text-audit research milestone. It does not establish clinical
evidence grades, calibrated confidence, cross-study comparability or autonomous-tool superiority.
Provider model identity is reported metadata, not independently authenticated equivalence.

- **v0.6:** task-aligned dedicated verifier comparison, fresh grouped evaluation and independent
  calibration protocol, improved compound-claim/qualifier diagnostics. Freeze criteria before
  consuming reserved evidence; do not tune on the exposed v0.4 test questions.
- **v0.7:** let measured audit signals drive retrieval and repair, then compare against a strong
  model with the same tools and fixed budget. Keep failures and negative results.

[Technical route](../verification-roadmap.md) · [Completed v0.5 scope](../plans/v0.5-text-verification.md)

Services are local-only. The web API has no public-user authentication or tenant isolation;
do not expose it as a hosted clinical application. Full Ask can persist questions in checkpoints.
Docker and macOS/Linux browser operation were not exercised on this Windows release host.

The existing offline suite passed (230 cases before the new replay regression), and the six
targeted audit/demo cases passed after adding it. Frontend tests/build and the historical report
check passed. A fresh Windows Python 3.12 environment installed from the README, installed
frontend dependencies and replayed/exported the medical record without a key file or RAGTruth
cache. The actual browser Ask and source navigation are recorded above. CI status is available on
[GitHub Actions](https://github.com/lijingshan-6/medrag-agent/actions/workflows/ci.yml).
